Cómo se arma

// Inicio: todos los procesos
<ListaTrabajo />
// Página del proceso: el proceso queda fijo
<ListaTrabajo proceso="segunda" />

interface Faceta {
  clave: string;
  etiqueta: string;
  opciones: Opcion[];
  valor(caso: CasoResumen): string | string[] | null;
}

const COMUNES: Faceta[] =
  [estado, termino, juzgado, entidad, alertas];

const PROPIAS: Record<TipoProceso, Faceta[]> = {
  segunda:  [decisionAQuo, impugnante, sentido2a,
             derecho, pruebasNuevas, porRevisar],
  primera:  [medidaProvisional, informes, tipoAccionada,
             derecho, especialProteccion, vinculados],
  desacato: [fase, cumplimiento, sancion, consulta,
             diasRequerimiento],
  penal:    [libertad, actuacion, audiencia, delito,
             ley, menor],
};

// Datos propios en la fila, por proceso
const FILA: Record<TipoProceso, (c: CasoResumen) => Dato[]>;
  1. Con el proceso fijo, por la prop o al tocar su pestaña en Inicio, sus filtros propios aparecen en un carril teñido junto a los generales, nunca debajo, y cada fila muestra sus datos. Inicio y la página del proceso muestran la misma lista.
  2. Cada filtro es una pastilla plegada que muestra su valor y su ✕. Al tocarla abre el control que le corresponde: lista con conteos, lista con buscador, pasos en orden procesal, o rango de fechas con presets e histograma de actividad. Los filtros de sí o no son interruptores de un toque.
  3. Estado y Plazos no son pastillas: la franja de estados (proporcional a los conteos) y las baldosas de plazo resumen y filtran a la vez.
  4. Cada opción cuenta los casos que quedarían con los demás filtros aplicados. Las opciones en 0 se atenúan pero no desaparecen, para que la lista de opciones no salte.
  5. Por defecto se ven los casos abiertos; el tramo rayado «Terminados · ocultos» de la franja los agrega con un toque.
  6. Un filtro sin datos para los casos visibles se oculta; por ejemplo, Juzgado de origen en penal.
  7. Los filtros van en la URL (#/?proceso=segunda&estado=decidir), así que una vista filtrada se puede guardar como marcador y el botón Atrás la conserva.
  8. En pantallas angostas los carriles se apilan y cada control sale como una hoja desde abajo. «Limpiar filtros» se puede deshacer, y si nada coincide la lista propone quitar el filtro que más casos devuelve.
  9. Reemplaza «Para continuar» de inicio/index.tsx y la lista de casos/index.tsx; Ficha recibe los datos propios del proceso como una lista más.

Decisiones pendientes del despacho

¿Desde cuándo corre el término?

Reparto o recibo en el despacho, y si se cuentan los festivos judiciales. Hasta decidirlo, «Término» y «Vence primero» no deben mostrarse.

¿«Trabajado» basta con la última actividad?

actualizado también cambia cuando el sistema termina una redacción. Separar «lo que yo trabajé» exige un registro de actividad por persona.

¿Qué plazo usa el desacato?

El de 10 días hábiles es una referencia jurisprudencial, no un término legal: debe ser configurable por despacho y la interfaz no debe presentarlo como término legal.

¿Cómo se clasifica el texto libre?

decision_a_quo y derechos_invocados son frases del modelo. Para filtrarlas hay que llevarlas a las categorías del filtro (palabras clave, con Jev como apoyo).
